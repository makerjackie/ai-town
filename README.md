# 模型镇 MODEL TOWN

一座用 Three.js 纯代码搭的 AI 夜市。西岸是 Claude / GPT / Gemini / Grok，东岸是 DeepSeek / Kimi / 智谱 / MiniMax，北面所有人给英伟达交 CUDA 税。

```bash
npm install
npm run dev
```

打开终端里的本地地址（默认 `http://localhost:5174`）。

- WASD 走路，点击画面锁定鼠标
- C 巡游 · V 鸟瞰
- L 或点左上角：切换排行榜（智力 / 用户 / 估值 / 性价比 / 开源 / 上下文）
- R 或点滑动变阻器：拧 DeepSeek 的价格
- 点击建筑看牌子

方法论来自 [techartist_](https://x.com/techartist_/status/2077433800276283523)：先写世界，再写能用盒子搭出来的形体，然后迭代光和比例。详见 `docs/blueprint.md`。
