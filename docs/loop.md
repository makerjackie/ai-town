# 模型镇 iteration loop

Don't stop until the user says stop.

On each tick:

1. Open `http://localhost:5174/` (Vite is on 5174). Screenshot cinematic + orbit.
2. Pick the ugliest or emptiest thing vs `public/refs/hero-plaza.png`.
3. Change **one** of: proportion, placement, light/bloom, a fun beat, denoise.
4. Fun beats still missing or thin: 法庭飞纸可读性、NVIDIA 从南门能看见、变阻器拧了人流变、估值气球、开源围栏、Kimi 走廊进深。
5. Keep 100% procedural. No GLB. Canvas for text.
6. If the scene is too bright, raise bloom threshold. If too empty, add lamps/stalls not more point lights.
7. Write a 3-line note in `docs/loop-log.md` (append).

Wake every ~8 minutes, or sooner if a screenshot just landed.
